# Supplementary Material: Integrating an MCP Server into bigArchiMate

This repository contains the supplementary material for my Bachelor's thesis at TU Wien (Vienna University of Technology) on enabling LLM-assisted ArchiMate modeling in **bigArchiMate** via the Model Context Protocol (MCP).

* **Source Code Implementation:** [paulllang/bigArchiMate](https://github.com/paulllang/bigArchiMate) (forked from [borkdominik/bigArchiMate](https://github.com/borkdominik/bigArchiMate))
